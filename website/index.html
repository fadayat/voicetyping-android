A narrow privacy boundary

Your key stays yours.

Encrypted on the device

Your Gemini API key is protected with AES-GCM and a non-exportable Android Keystore key.

Session memory only

Audio supports the active live session and fallback. VoiceTyping does not write recordings or transcript history to disk.

Focused paste only

The accessibility service invokes paste for the active editable field. Password fields are excluded.

Common questions

Does VoiceTyping replace my keyboard?

It keeps your current keyboard. The floating orb starts and stops voice capture while you stay inside the app and field you selected.

Why does it use an accessibility service?

Android uses that service to invoke the standard paste action in the focused editable field. VoiceTyping does not subscribe to accessibility events or store field contents.

Which languages are supported?

The current beta is configured for Azerbaijani. More languages are planned, but they will only be listed as supported after testing.

What does it cost?

The app is open source. Transcription requests use your Gemini API key, so Google quota, pricing, and terms apply to your account.
